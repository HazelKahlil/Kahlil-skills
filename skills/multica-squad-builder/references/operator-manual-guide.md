# Operator Manual Guide

Use this when the user wants a prompt to give another agent.

The prompt should explain:

1. What Multica-Squad-Builder is.
2. That it is a builder Skill, not a fixed project SOP.
3. That the agent must ask only high-impact setup questions.
4. That names and roles are user-provided.
5. That Captain, Worker, Reviewer, Analyst, and Human Owner stay separate.
6. That the output must be a DRAFT setup pack until live checks pass.
7. That 100% confidence means red-team loop plus live checks, not mathematical certainty.

Use `templates/operator-manual-prompt.md` for a copyable version.
