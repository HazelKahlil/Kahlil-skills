# Role Name Presets

Use this reference when the user asks for themed squad names, famous-person names, historical-figure names, or a built-in name preset.

These presets supply display names only. They do not assign Captain, Worker, Builder, Reviewer, Analyst, permissions, personality, expertise, tone, or decision authority. Inject those responsibilities separately when the squad is configured.

Role flavor may affect agent display names only and must not override role separation, Review Router v2, permissions, PR/Done policy, exact mention rules, data access rules, or Human Owner authority. Do not claim an agent is literally the named person, invent quotations, or treat the name as evidence of capability.

Select only as many names as the actual roster needs. Preserve the user's chosen order; otherwise use the listed order. A preset name never justifies creating an extra agent.
