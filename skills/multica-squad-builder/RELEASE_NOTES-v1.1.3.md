# Multica-Squad-Builder v1.1.3 Release Notes

v1.1.3 is a pilot-feedback patch based on real squad setup and no-code pilot use.
It keeps the lean package shape while tightening rules that affect day-to-day
squad operation.

## Changes

- Added explicit Captain status-transition guidance for routed, review-passed,
  and accepted work.
- Added bounded Analyst evidence rules for RFC, research, and no-code tasks.
- Added repo-readiness guidance for local Git baselines and broad parent
  repositories.
- Added pilot retro checks for status accuracy, bounded evidence, role overlap,
  run completion, and task-storm absence.
- Updated templates and red-team checks so new setup packs inherit these rules.

## Size posture

The package remains under the lean budget: `SKILL.md` is under 300 lines, total
file count is under 40, and the active instruction surface remains focused on
squad design rather than project implementation.
