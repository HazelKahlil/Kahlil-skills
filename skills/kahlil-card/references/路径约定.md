# 路径约定（中文）

> 为方便在访达里辨认，**任务目录与成图输出一律用中文路径**。
> Skill 本体目录名 `kahlil-card`、模板内技术路径 `assets/fonts` 保持英文，避免破坏代码引用。
> **例外：`Live-Photo` / `Live Photo` 一类技术名可以保留英文**（见下「可保留英文的名字」）。

## 默认落盘（工作区 · platforms · 按日分层）

正式卡片任务落在 **平台分区** 下，并按 **年 / 月 / 日** 分层；同一天可有多个专题。每次渲染再在 `输出/` 下建 **时间戳子目录**。

```text
<your-workspace>/
└── platforms/
    ├── 公众号/
    ├── xiaohongshu/
    └── Kahlil-cards/                         # ★ kahlil-card 专用
        └── 2026年7月/                        # 年月（不补零）
            └── 23日/                         # 日（不补零）
                └── <专题中文名>/
                    ├── index.html            # 源文件（技术名，可保留英文）
                    ├── render.mjs            # 渲染入口（从 skill 拷贝）
                    ├── assets/               # 内部：字体等 symlink
                    │   └── fonts → skill
                    ├── 素材/                 # 用户素材（可选）
                    └── 输出/                 # ★ 成图总目录
                        ├── 16时06分/         # 某次渲染时间戳
                        │   ├── 卡片-01.png
                        │   ├── 卡片-02.png
                        │   ├── 发布文案-初稿.txt
                        │   ├── 发布文案.txt
                        │   └── AI-Look-检查报告.md
                        ├── 16时42分/         # 另一次重渲
                        │   └── …
                        └── 最近 → 16时42分   # 软链，指向最近一次
```

相对路径简写：

`<workspace>/platforms/Kahlil-cards/<YYYY年M月>/<D日>/<专题中文名>/输出/<H时MM分>/`

### 专题中文名怎么起

用**能一眼看懂的中文**，**不要把日期写进专题名**（日期已在上层目录）。避免纯英文 slug。

| 推荐 | 不推荐 |
|------|--------|
| `给AI小白的10个工具清单` | `ai-tools-20260723` |
| `AI原生-不是答案` | `AI原生-不是答案-20260723`（日期冗余） |
| `郭麾摄影-封面选型` | `guohui-photo` |
| `咖啡实况-Live-Photo`（专题中文 + 技术后缀可） | 纯 `live-photo-demo` |

禁止字符：`/ \ : * ? " < > |` 以及首尾空格。
可用：中文、字母、数字、`-`、`_`、`·`。

### 子目录中文名

| 用途 | 目录名 |
|------|--------|
| 成图 / 导出总目录 | **`输出/`**（默认，必用） |
| 某次渲染批次 | **`输出/<H时MM分>/`**（`node render.mjs` 自动建；撞名追加 `-2`） |
| 最近一次成图 | **`输出/最近/`**（软链 → 最近时间戳目录） |
| 用户素材（可选） | **`素材/`** |
| 字体与内部资源 | `assets/`（技术目录，模板相对路径依赖它） |
| Live Photo 分包（可选） | 可放在 `输出/<时间戳>/Live-Photo/` 或该批次目录平铺 |

### 与历史目录的关系

| 路径 | 角色 |
|------|------|
| **`platforms/Kahlil-cards/<YYYY年M月>/<D日>/<专题>/`** | **新任务默认**（正式归档） |
| `platforms/Kahlil-cards/<专题>/`（无年月日） | **旧扁平结构**，只读兼容；新任务不要再建 |
| `本地测试/` | 旧任务兼容目录；**不要再建** |
| `local-tests/` | 旧任务兼容目录；**不要再建** |
| `output/`（英文） | 旧任务兼容 symlink → `输出/` |
| 直接写在 `输出/卡片-01.png`（无时间戳） | 旧行为；新默认写 `输出/<时间戳>/`。需要旧行为时：`node render.mjs --flat-out` |

## 可保留英文的名字

这些**不要求**改成中文，保留更利于对接脚本 / 苹果生态 / 上游文档：

| 类型 | 可保留英文 | 说明 |
|------|------------|------|
| 功能/格式名 | `Live-Photo`、`Live Photo`、`.pvt`、`.mov`、`.jpg` | 用户已确认：**Live-Photo 这类名字可以保留** |
| Apple 资源名 | `IMG_xxx.JPG`、`IMG_xxx.MOV`、`IMG_xxx_LIVE.pvt` | 实况导入依赖这对命名习惯 |
| Skill / 代码路径 | `kahlil-card`、`assets/fonts`、`index.html`、`render.mjs` | 代码引用，不翻译 |
| 平台分区英文名 | `platforms`、`xiaohongshu` | 既有项目结构 |
| 版式编号 | `S01`–`S12`、`M01`… | 配方代号 |
| 历史目录 | `output/`、`本地测试/`、`local-tests/` | 只读旧任务 / 已归档 |

**仍要用中文的：**

- 卡片归档根 → `platforms/Kahlil-cards/`
- 日期分层 → `2026年7月/23日/`
- 专题任务目录名 → `<中文专题>/`
- 成图总目录 → `输出/`
- 渲染批次 → `16时06分/`（中文时分）
- 普通静图文件名 → `卡片-01.png` 等
- 对话里给用户看的路径 → 整段中文为主（Live-Photo 段可夹英文技术名）

## 成图文件名

| 规则 | 示例 |
|------|------|
| 默认静图按页序 | `卡片-01.png`、`卡片-02.png` |
| 若 HTML 里 `.poster` 的 `id` 已是中文 | 直接用该 id，如 `封面.png` |
| 微信宽图/方图 | `微信-21x9.png`、`微信-1x1.png`（若 id 如此命名） |
| **Live Photo** | 父目录仍用中文专题 + `输出/<时间戳>/`；**文件/包名可保留英文技术名** |
| 发布文案 | 同一次时间戳目录保存 `发布文案-初稿.txt`、最终 `发布文案.txt` 和 `AI-Look-检查报告.md` |

### Live Photo 落盘示例（技术名保留）

```text
platforms/Kahlil-cards/2026年7月/23日/咖啡拉花-实况/
└── 输出/
    └── 14时30分/
        ├── 封面静帧.png
        └── Live-Photo/
            ├── IMG_咖啡_01.JPG
            ├── IMG_咖啡_01.MOV
            └── IMG_咖啡_01_LIVE.pvt
```

渲染脚本会把常见英文静图 id 映射为中文文件名（见 `scripts/render-task.mjs`）。
Live Photo 打包脚本输出的 `JPG/MOV/pvt` **不要强行改成纯中文文件名**，以免破坏配对与导入。

## Agent / 命令行

```bash
# 初始化（专题名用中文，不含日期）→ 自动落到当日分层
bash <skill-root>/scripts/init-task.sh \
  --name 给AI小白的10个工具清单
# → …/platforms/Kahlil-cards/2026年7月/23日/给AI小白的10个工具清单/

cd "…/platforms/Kahlil-cards/2026年7月/23日/给AI小白的10个工具清单"
node render.mjs
# → 输出/16时06分/卡片-01.png …
# → 输出/最近 → 16时06分

# 需要直接写到 输出/ 根（旧行为）时：
node render.mjs --flat-out

# 补档到指定日：
bash …/init-task.sh --name 某专题 --year 2026 --month 7 --day 23
```

环境变量（可选）：

- `KAHLIL_CARD_ROOT`：工作区根；未设置时使用当前工作目录
- `KAHLIL_CARD_OUT_ROOT`：任务归档根，默认 `$KAHLIL_CARD_ROOT/platforms/Kahlil-cards`
- `KAHLIL_CARD_SKILL`：skill 真源路径

## 对话交付时怎么写路径

给用户看时**优先整段中文路径**，例如：

`<workspace>/platforms/Kahlil-cards/2026年7月/23日/给AI小白的10个工具清单/输出/16时06分/卡片-01.png`

或指最新：

`…/输出/最近/卡片-01.png`

Live Photo 可写成：

`…/2026年7月/23日/咖啡拉花-实况/输出/14时30分/Live-Photo/IMG_咖啡_01_LIVE.pvt`

不要只丢扁平旧路径 `platforms/Kahlil-cards/<专题>/输出/` 当**新任务默认**（除非在指历史文件）。

## 与 Skill 本体的边界

| 位置 | 放什么 |
|------|--------|
| `skills/kahlil-card/` | 模板、字体、文档、脚本（安装真源） |
| `platforms/Kahlil-cards/<年>/<日>/<专题>/` | 每一次你的文案 → 卡片任务与成图 |
| **禁止** | 把成图写进 skill 根目录 |

## 用户指定其它目录时

若用户明确说「存到某某文件夹」，尊重用户路径，但仍优先用**中文目录名 + 日期分层 + `输出/<时间戳>/`**；Live-Photo 技术文件名仍可保留英文。
