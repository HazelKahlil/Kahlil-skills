# Font slots

The public package intentionally does not redistribute commercial font binaries. The templates keep these relative paths so a reviewer can reproduce the accepted look with properly licensed local copies:

- `Futura-Medium.ttf` — default Latin display
- `CanelaText-Regular.ttf` — optional Latin display alternative
- `ruizi-xianxi.ttf` — default Chinese display title

Place licensed copies in this directory when rendering, or let the CSS fall back to the system font stack. Additional FZ/Ruizi fonts used in private workspaces are also user-supplied and are not part of this repository.
