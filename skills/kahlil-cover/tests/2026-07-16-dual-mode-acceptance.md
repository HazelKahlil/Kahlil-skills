# Cover 双模式定稿回归

## 用户确认

- Cover 只维护两种正式输出：`IP 角色版` 与 `内容视觉版`。
- 用户没有指定模式时，必须先询问，不能擅自选择。
- 用户提供满意成图或参考图时，以参考图作为覆盖层校准构图、字体层级、配色和画面密度。
- 标题文字不得改写，分行可调整，标点可省略。
- 右下角保留很小的 `Kahlil`，不得像旧徽章一样突出。

## IP 角色版定稿基线

- 接受图 1：`assets/accepted/2026-07-16-vibe-coding-ip-orange.png`
- 接受图 2：`assets/accepted/2026-07-16-vibe-coding-ip-black.png`
- 固定人物来源：`kahlil-artwork` 的 canonical reference images。
- 视觉共同点：纯白背景、标题优先、重点短语放大、人物与文章动作位于下半区、黑色与深棕为主体、焦橙色只做重点词或细线强调。
- 字体共同点：所有中文标题行统一使用同一套粗黑体/黑体，英文核心词使用超粗无衬线；通过字号、行距和位置形成标题层级，不再把上方中文改成宋体。
- 文章仍决定人物正在完成的动作与隐喻；固定的是人物身份和视觉语言，不是每篇都复用同一个纸盒。
- 不设置房间、办公室、书桌或写实环境，除非用户明确要求。

## 内容视觉版基线

- 不强制使用 Hazel 观察者。
- 文章内容决定人物、物件、环境、摄影或插画风格、色彩与光线。
- 不得把其他文章的莫兰迪静物、人物或隐喻带进当前封面。

## 通过条件

1. Skill 能正确询问并区分两种模式。
2. IP 角色版输出角色参考图、上传说明和可复制提示词。
3. 内容视觉版输出文章 brief 和可复制提示词。
4. 两种模式都默认 `3:4`，标题不改写但可省略标点，右下角只有很小的 `Kahlil`。
