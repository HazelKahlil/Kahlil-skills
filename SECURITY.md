# Security Policy

## Sensitive Data

Do not open issues or pull requests that include secrets, private workspace data, local credentials, cookies, API keys, personal files, databases, private screenshots, or internal issue links.

If sensitive data is accidentally published, rotate affected credentials first, then remove the data from Git history before continuing.

## Reporting

For private security concerns, contact the repository owner through a private channel. Do not disclose exploitable details in a public issue before the owner has had time to respond.
